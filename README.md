# NEXO – Protótipo

Protótipo de aplicativo para jovens planejarem a carreira (diagnóstico, objetivo, competências, plano e acompanhamento).

**Este é um protótipo.** O login com Google, iCloud e e-mail é simulado, os dados ficam apenas no navegador de quem usa, e o ID sequencial definitivo (NX000001...) exige um servidor. O conteúdo de carreiras ainda não foi revisado por especialistas e o texto de privacidade é um rascunho sem revisão jurídica.
